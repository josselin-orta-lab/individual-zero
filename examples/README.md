# Examples

The files in this directory are **illustrative examples**.

They are not scientific evidence, active project decisions, or reference behavior.

Use them to understand how the repository workflow is meant to look before creating real project records.

## Available examples

- [Repository placement](repository-placement.md): where common types of work belong.
- [Example EXP](example-exp/README.md): a fictional experiment record.
- [RAI example](rai-example.md): a fictional reuse/adapt/implement decision.
- [Adapter example](adapter-example.md): how an external component can be connected without hiding cognition in the adapter.
- [ADR example](adr-example.md): what a shared architectural decision record could look like.
- [Bootstrap run](bootstrap-run-example.md): what the current executable technical scaffold emits.

## Rule

If an example becomes real work, create a proper Issue, EXP, benchmark, adapter, or ADR in the relevant project location. Do not cite an example as evidence.
