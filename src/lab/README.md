# Lab

The Lab is neutral research infrastructure. It runs, observes, measures, and reproduces executions.

Typical responsibilities include experiment runtime, simulation, logging, telemetry, metrics, seed management, artifact collection, and reproduction tooling.

The Lab should not contain I0-specific memory, affect, motivation, action-selection, self-model, or other cognitive mechanisms.

A useful test is: **would this code still be useful for I1 or a competing architecture?**
