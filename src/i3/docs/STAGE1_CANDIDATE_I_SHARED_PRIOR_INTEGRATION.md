## Candidate-I composition

### First contact

The inherited RMS/omega effect prior is shared across imagined and directly
perceived unsupported trials exactly as in #1170.

Relevance rules stay frozen:

- imagined trial: Candidate-H's strict first-contact rule;
- perceived trial: #1170's decision-top rule.

If the first-contact trial is RELEVANT, the candidate information geometry is
retained.

If it is FALLBACK, the paid probe remains charged and the complete final
decision is recomputed from the post-probe body using the ordinary P1.3 Mind
with **both legacy score addends discarded**:

- curiosity applied = 0;
- risk/prudence applied = 0;
- no Candidate-F ordinary score may leak into fallback.

This fallback is called `P1.3_BASE_FINAL`. It is not historical P1.3 and must
not be reported as reference identity.

### Post contact

Post-contact behavior is not redesigned here. It must remain exactly the #1163
Candidate-H rule:

- personal actionable belief determines support;
- information changes the final geometry only when it changes the decision top;
- otherwise the same paid P1.3 fallback semantics from #1163 are retained;
- omega and the shared inherited first-contact prior are not read post-contact.
