# i3 Stage-6-light: detached resource-transition reconstruction (15 Nov 2026)

**Software preflight only, NOT an experimental authorization or a biological result.** This is a bounded correction to PR #1403's known limitation: it previously verified physiology only for actions without resource gains, allowing a fully self-consistent but physically impossible declared `boire` or `manger` step to evade physical scrutiny. The intervention changes the **auditor**, not native `World`, `Mind`, genesis, the study rules or any of the earlier original bytes.

## Falsifiable claim

Given one **supplied** Stage6-compatible native-v2 original with a complete `keep_trace=True` trace, source/snapshot/cost envelopes already validated by the existing read-only auditor, and the serialized native initial `world_snapshot`, can an isolated reconstruction of deterministic resource/motor effects reproduce **every** declared physical body state and position, including water-source stock, carried food, token effects, restock cycles and scheduled ecological changes?

Falsifiers include: drinking without a present/in-stock source; collecting an absent/out-of-stock token; eating without previously collecting it; wrong token, movement off-grid, extra/spurious body gain, incorrectly timed restocking or pulse, a malformed/duplicate source, an edited law or effect, any mismatch with the native physical transition/death vector, and an altered hash/cognitive ledger. The same original auditing, complete trace, SHA-256 provenance equality and model-funded energy/vigilance checks from #1402/#1403 remain prerequisites. The 5-channel physical body is independently computed for **all** declared actions, not only effect-free ones.

## Explicit execution boundary

`stage6_light_resource_shadow.py` is a deterministic **dictionary-only** reconstruction of the already-supplied `WorldSpec` snapshot. It uses no native engine/World/Mind/runtime import, seed selection, birth, `run_life`, network call or archive writer. It starts from the declared `spawn`, empty inventory and source stocks. For each declared action it computes source/food/token effects, checks ownership and availability, and then applies **restock before scheduled changes** exactly as `World._step` does. A command error does not mutate the shadow state. It emits only positions and effect increments, not Mind's alleged motivation, survival, genome or fitness.

The existing `stage6_light_trace_funding_preflight.inspect_traced_life` is the entry point and still demands the full supplied native-v2 envelope and complete trace. It checks shadow motion against hashed positions, feeds the shadow effects into an independent mirror of `body.transition` with declared paid decision work, and checks the computed post-motor body and cause(s) of death against the learning-phase receipt before recomputing trace/evidence terminal chains. It reports an explicit count of resource steps checked and **zero** accepted resource steps skipped. If a native record is missing a full trace, it fails instead of silently downgrading the claim.

## Tests and known limits

All **new** fixtures are invented. Unit tests cover finite/unlimited stock, collection-before-eating, scheduled stock/gain changes, event ordering, restocks, transactional refusal, malformed source/effect and deny-all endpoints; integration tests build a fully self-consistent fictional fatal receipt including drinking, moving, collecting and eating, using the real **pure** `body.transition` only as a test oracle (never instantiating `World` or `run_life`). Forgeries are also *re-sealed* consistently after changing the declared water gain, stock or food effect, to ensure they are rejected by **physics** rather than merely by broken hashes. Source-exact Python 3.11 and 3.12 CI are required before merge.

**Still NOT_ATTESTED:** whether these declared actions were actually selected by a native Mind, whether the supplied trace genuinely ran in a World, independent timestamp/first exposure, independent remote source and allocation custody, chronologically precommitted parent/founder/mutation seeds, G/S/R sealed order, independent ecological populations, full-panel 11,520-life original replay, ADR-0017 G/S/R exception, an engineering rehearsal, or scientific authorization. A malicious source can still fabricate a completely plausible original and all of its self-declared seals. This is a regression test of computational *consistency*, not historical authenticity or demonstrated adaptive benefit.

The prior fixed method remains **`METHOD_FIXED_PREAUTH_NOT_EXECUTABLE`**, all admission/World/rehearsal flags remain `false` and pins `null`. `I1` remains active, `I3` is an unregistered development reference, P1.3 funded-v2 stays unchanged, Stage 2.1 is `NOT_ISSUED/HOLD_NO_VERDICT` and Stage 6 is `STAGE6_LIGHT_NOT_RUN_NO_AUTHORIZATION`.
