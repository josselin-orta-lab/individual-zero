## Scientific distinction

The completed 64-unit GATE versus RANDOM-EQUAL-MEAN developmental panel did not compare prioritized versus random memories; RANDOM changed only the nominal 6/7 **number** of replays. The [48 synthetic detached Mind trials](CONTENT_SELECTION_LOCAL_RESULTS_2026-11-10.md) showed immediate learned-state differences in 47/48 snapshots when content was changed at constant prepaid replay count. This is not a survival result.

The next diagnostic needs to prove a **full embodied trajectory** can execute an opt-in intervention that changes only **which eligible personal memory** is replayed, while keeping the original stakes-based GATE decision about **how many** are requested, the exact prepaid replay work tariff, body/World laws, control, innate needs, genome and Action Competition. It must not introduce any prescribed adaptation or environmental knowledge into an individual.

## Frozen technical allocation, not a scientific cohort

New (unused) PUBLIC synthetic F0 WorldSpec rows **144–155 inclusive**, exactly **12 matched pairs, 24 technical lives, horizon 400**. Within a pair, starting WorldSpec, genome seed and life seed match, and arms run in fixed order:

1. `p13_replay_gate_v1`: historical funded GATE replay quantity, existing TD-error priority memory content.
2. `p13_replay_gate_random_content_v1`: the same historical GATE replay quantity `k`, but memory indices selected uniformly without replacement using an independent life/sleep-seeded HMAC stream from current *eligible* buffer entries.

The two branches may diverge later in their life trajectories, learned states, available memories, sleep counts and realized replay bills. Matching their **algorithmic count decision** does **not** imply exactly equal realized per-life counts or costs. Per-comparison World laws remain unchanged. No genome fitness selection or prescribed survival rescue rule is added.

The entirely new `gate_random_content` mode is separately named, guard-admitted and traceable. It is **not** a silent change to `P1.3`, old GATE, or historical RANDOM. `Mind.learn_from_outcome` preserves its original priority order when no explicit experimental replay selector is supplied. Only the new opt-in mode passes a novel selection function after base prepaid outcome learning, and the TD updates are actually performed with same allowed `replay_limit`. The selected memory indices derive only from internal buffer length, own life seed and sleep ordinal. They never inspect WorldSpec, hidden resources, global RNG or future outcomes.
