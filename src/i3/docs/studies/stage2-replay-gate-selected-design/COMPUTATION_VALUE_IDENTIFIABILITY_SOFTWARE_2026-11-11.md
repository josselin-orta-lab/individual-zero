## Precise falsifiable question

Given only a previously **fixed motor action** and the same inherited
body-distress function, can we separate (i) immediate direct cognitive
cost, (ii) post-action plus post-learning cost and displaced learning,
(iii) sleep-mediated food/integrity loss and terminal, and (iv) **causal
information benefit**, which is **not identifiable** without a changed
later action and actual first-person outcome?

Using only native `BodyLaws`, `CognitiveBudget`,
`transition`, `Mind.prepare_learning` and an inherited
`Mind.feats/distress` readout, compare three **fixed-action,
pure-model** arms for every cell:

- `reference`: the same original selected action, with only
  `CognitiveWork(cycles=3,memory_items=12)`.
- `paid_visible`: **after native model advance authorization**,
  compute the three existing passive action/global/persistence forecasts
  from the same explicitly **synthetic** action-indexed EffectsModel,
  and include the proposed optional
  `CognitiveWork(cycles=6,memory_items=48)` before the motor transition.
  These values are exposed only to the external laboratory audit, never
  returned into `Mind.decide` or future motor control.
- `paid_discard`: authorize and execute **the same three** lab
  forecasts and same native model work, but discard the reported
  forecast values after a laboratory checksum. Only the observer
  visibility differs, not the actual embodied computation work.

When an optional ticket cannot pay the motor reserve, **both paid
arms must reject atomically** and behave identically to the reference.
No readout, scan, hash or forecasting before native admission.
No assertion that this category tariff is true CPU/joule conversion.

Compare the original **immediate post-action** body and actual
native `Mind.prepare_learning` allocation on a new native allowance.
If the base/available replay learning work could be authorized,
apply only pure `debit_cognition` to obtain a **projected**
`POST_PAID_LEARNING` body; no `World.pay_cognition`, no actual
`Mind.learn` or modified learned effects/memory/RNG is permitted.
If native terminal, do not pay learning. Preserve explicit null
unfunded statuses and actual terminal causes from pure laws.

Define **cost-only native personal model value**, *not* value of information:
`R = -Mind.distress(Mind.feats(body))` for nonterminal,
`R = -d_max` for terminal. Report both future phases and
`ΔR_cost_only = R_optional_post_learning - R_reference_post_learning`
when optional admitted. **Do not assign an observed benefit** to the
forecast: `expected_information_gain`, `net_value_of_computation`,
`future_action_mediation` and `generalized_survival_benefit`
remain **unidentified/null**, not numeric zero. The readout can
be informationally distinct yet never consumed by Action Control.
The paid-visible and paid-discard arms must have **exactly the same**
body, learning allowance, native terminal and personal scalar R, while
the reference may legitimately differ due to extra cost.
