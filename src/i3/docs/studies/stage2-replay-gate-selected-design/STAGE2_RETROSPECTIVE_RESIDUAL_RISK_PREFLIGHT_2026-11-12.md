It tests a possible source of self-uncertainty information, **not its causal information value or its ability to change action**.

## Precommitted deterministic online estimators and two proper scores

Within *each* of four trajectories, process rows in ascending original step order. For each row t, let `y_t` = recorded actual five-channel POST_PAID_LEARNING body delta and `p_t` = previously frozen original `EffectsModel.predict` five-channel mean. Define the nonnegative, observed native prediction-error magnitude `z_t = (1/5) * sum_c (y_t[c] - p_t[c])**2`. **Compute `z_t` only after BOTH risk forecasts for step t have been frozen**. All data are historical, so "before" describes the deterministic replay's access discipline, NOT a new prospective outcome.

Maintain only earlier `z_i`, i < t:
- **Pooled online control:** `G_t = sum_{i<t} z_i / (t-1)` if any history exists, otherwise 0.0.
- **Action-conditioned, shrunken online diagnostic:** For the *original already chosen* motor label a, `A_t = (sum_{i<t,action_i=a} z_i + G_t) / (1 + count_{i<t,action_i=a})`. One pooled-mean pseudorecord is a **fixed** smoothing convention, not a learned rule or a tuned hyperparameter. With no prior same-label error it reduces exactly to `G_t`. The action label is a coarser key than the actual native EffectsModel's action/token key; report this mismatch.
- Then observe `z_t`, compute per-event **proper quadratic risk prediction loss** `(z_t - G_t)**2` vs `(z_t - A_t)**2`, plus **absolute risk prediction loss** `abs(z_t - G_t)` vs `abs(z_t - A_t)` as a predeclared heavy-tail sensitivity diagnostic. This is a risk-of-future-native-forecast-error target, not an observation of action utility.
- Only AFTER both scores are measured may `z_t` update pooled and action-specific cumulative records. No across-world history sharing, no future-state condition, no action choice or readout selection. No thresholding on `boire`, no tuning action labels, no parameter sweep, no exceptions for extreme losses.

For **every** unit, print count, means of both squared-risk and absolute-risk scoring rules, gains `control - action`, number of steps with available prior same-label history, and all-action/no-history coverage. Aggregate 320 events descriptively; also report signs of each complete 80-step technical unit. These are four **technical** trajectories sharing two DEV Worlds, not independent ecological populations; never treat 320 autocorrelated steps as independent evidence. Do **not** manufacture confidence intervals, p-values, standardized body energy costs, or survival effects. Source agreement checksums do not provide independent attestation.
