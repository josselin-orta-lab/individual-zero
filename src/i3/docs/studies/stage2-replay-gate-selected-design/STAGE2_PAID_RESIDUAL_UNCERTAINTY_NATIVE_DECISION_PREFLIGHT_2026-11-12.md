## Specific hypothesis and distinct source

#1352 showed real World funding of prediction and residual storage, but its laboratory error ledger was never consulted. #1349 found a retrospective action-label-conditioned estimate of **own past prediction error**, distinct from E3's distribution of raw empirical outcomes. The present **separate lab-only Mind subclass** will (a) retain exactly the *same* paid own-error ledger in BOTH arms, and (b) **on the NEXT native decision**, read that ledger through a new **bounded CognitiveBudget** gate inside the already existing native `Mind.simulate` path. `VISIBLE` substitutes only the *uncertainty scalar* returned by the existing native effect prediction; `PAID_DISCARD` fully computes it but returns the original uncertainty. The original effect **mean**, options, native need weights, scoring, Competition, Action Control and RNG remain untouched. The lab does not choose, override or rerank a motor.

The fixed, not fitted, uncertainty transform is `risk = (same_action_sum_of_prior_squared_errors + pooled_mean)/(1 + same_action_count)`, with `u_error = sqrt(risk / (1+risk))`, which is bounded in `[0,1)` and nonnegative. It is the already frozen #1349 one-pseudorecord estimator, passed through a monotone dimensionless map to native uncertainty range, NOT newly calibrated probability or confidence. If no history or no prior same-action error, return the original uncertainty in BOTH modes **after** any admitted read operation, and label `NO_PERSONAL_SUPPORT`. If the optional read cannot be afforded, return the original uncertainty with no optional history copied/read. Renaming first-person action identities must not expose world/source names.
