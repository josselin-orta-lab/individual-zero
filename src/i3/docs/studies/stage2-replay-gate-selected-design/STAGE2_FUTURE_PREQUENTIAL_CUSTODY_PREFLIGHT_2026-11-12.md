## Why / how this differs from existing probes

The native `EffectsModel` computes action-dependent mean deltas. A prior synthetic witness (#1357) proved that *past own errors* are not reconstructible from final native mean/count and the three latest branch outcomes; it did **not** test whether that error memory improves future predictions or an individual's decision. The existing `stage2_prequential_effect_audit.py` is linked specifically to historical replay-content P/R comparisons, which do not modify native action-effects forecasting. Rather than rerunning old inputs or fitting another risk estimator, implement a **generic, future-facing no-World recorder** that can later compare **one prospectively frozen candidate conditional-mean forecast against one cheaper frozen baseline**, event by event, under a real separately authorized source.

This recorder is neither a model nor a treatment. It cannot supply any information to `Mind` and cannot decide how much work to buy. It must make a future test **impossible to report as successful** if the only available evidence consists of post-outcome forecasts, survivor-only samples or missing outcomes imputed as zeros.

## Frozen implementation

- New pure `src/i3/lab/stage2_future_prequential_custody.py`, one matching `tests/i3/test_stage2_future_prequential_custody.py`. No changes to native `Mind`, `BodyLaws`, `World`, learned stores, `ACTIVE_SURFACE`, old result files or experiments.
- A bounded in-memory ledger initialized with fixed nonempty **unique assigned unit IDs** and an exact **source SHA-256**. A unit's next event must have sequence `len(settled)+1`, **exactly one pending forecast**, and all data must be finite five-channel vectors. A `freeze(unit, step, baseline, candidate)` returns a deterministic hash over the frozen source/unit/sequence/forecasts and preceding receipt head. Before `settle(unit, digest, actual)`, no scored actual delta exists.
- `settle` must validate the exact digest and an actual five-channel delta; score both predictions with the **proper five-channel squared-error loss for conditional MEANS**. Track candidate-minus-baseline signed paired difference; negative is better, positive worse. Strict no mutation of caller-owned vector inputs; compare against the already sealed predictions.
- `close` records **all** units as one of: `COMPLETE`, `NO_PERSONAL_SUPPORT`, `DENIED_FUNDING`, `DEAD_BEFORE_OPPORTUNITY`, `RIGHT_CENSORED`. Close with a pending forecast permitted only for `RIGHT_CENSORED` or `DEAD_BEFORE_OPPORTUNITY`, and it must preserve the frozen prediction as an explicit **unscored** event; neither is a successful zero-loss prediction. `COMPLETE` requires at least one scored event and no pending work. No events after close. All units must be closed before any aggregate report.
- The report includes **all assigned units**, counts for scored vs censored/never exposed, per-unit scored loss means, mean of per-unit candidate-minus-baseline differences **only on evaluable units (descriptive)**, per-unit harmful/beneficial signs, and worst per-event tails. Never pool correlated steps as independent ecological replicates, report inference p-values, or drop harms/deaths.
- Pure source SHA/hash only checks internal exact bytes; **no claim of external authenticated provenance**, actual real-time timestamp integrity, valid source genealogy, independent unit draw, biological marginal value, remote witness, physical native financing, CPU joules, survival non-inferiority or Stage-2 scientific closure.
- Tests must cover complete/censored/no-support/denied/dead, fixed denominators, late and duplicated events, mutated inputs and wrong hashes, malformed/nonfinite values, equal-forecast control, adverse tail, deterministic receipt digest, no import of `World`/new life. Validate in GitHub Python 3.11/3.12 on one exact SHA; do not run any scientific World or reproduce historical F0/DEV trajectory.

## Falsifiers, stop

**Engineering FAIL** if caller can change a frozen forecast after an outcome, score without a prior freeze, remove an assigned null, replace an adverse sample, silently treat censor/death as an actual zero, inflate unit N from repeated steps, or use a forged digest. Fix the guard, not the old experiment data.

**Software PASS** means only a valid ledger abstraction exists. It cannot adjudicate candidate utility without a genuinely independent future source and an independently specified predictive and cost design. No derived predictor is implemented here, and the earlier #1353 zero-clean-motor result, E3 negative and Stage 2.1 `NOT_ISSUED` remain unchanged.
