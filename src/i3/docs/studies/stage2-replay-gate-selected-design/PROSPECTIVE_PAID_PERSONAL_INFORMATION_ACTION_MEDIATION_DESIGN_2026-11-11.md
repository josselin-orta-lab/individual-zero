## 1. Why this specific question, not another proxy

The source-locked 256-cell fixed-action study ([#1302](https://github.com/josselin-orta-lab/individual-zero/pull/1302)) established modeled two-currency cost and possible lost subsequent learning, not an informational benefit: there was no motor response to the additional calculation. The source-claim next-action validator ([#1305](https://github.com/josselin-orta-lab/individual-zero/pull/1305)) can reject shadow, unaffordable and censored chronology, but neither authenticates a born source nor delivers a readout. The subsequent old-original audit ([#1307](https://github.com/josselin-orta-lab/individual-zero/pull/1307)) verified the already-consumed 48 original lives and showed that the one differing priority action among 20 captured comparisons was a **detached alternative**, not a second actual World action. It cannot be recruited as a new delivered-readout experiment.

**Falsifiable question:** does making *personally derived, physically funded* predictive information available through the individual's existing admissible decision process produce a genuine later action difference and a favorable *net personally lived bodily outcome*, compared with the **same actual calculation, same payment, and discarded information**?

- Null mechanisms are fully legitimate: no information-specific prediction difference, no use by native decision scoring, no action change, equal outcomes, harm from extra cognition, worse forecast calibration, or no exposure before death.
- Improved proper predictive loss alone does not establish action utility. A different detached action alone does not establish living mediation. More survival without identifying the controller intervention does not identify the informational path.
- No developer-specified `boire`/`manger`/`dormir` preference, goal override, artificial reward bonus, hidden World query, life rescue or postmortem replay is permitted.

## 2. Single smallest admissible architectural intervention (proposal, not implementation)

The new feature, if authorized for source engineering, should be an **opt-in, versioned and fully paid information handoff** at the boundary between experience-derived prediction and the *unchanged authority of native motor Competition*. This is not a second policy or a controller choosing an action on behalf of the individual.

1. **Personally paid evidence only.** Before an intervention point, observations must have entered through genuine first-person `World` consequences and the native, paid learning path. Native `Mind.effects.stats` contains action-conditioned personally experienced effect estimates. Conversely, native `Mind.buffer` contains only `(abs(TD-error), before-body, after-body, dead)` and no action identity. Never infer an action label from this buffer, borrow the future label or treat an observer as an organism memory. If the candidate needs transition/action binding beyond `effects.stats`, introduce a separately versioned, origin-authenticated, **paid** first-person storage path for *future* lives; this is a separate design and cost gate.
2. **Genuinely additional computed information.** Freeze one bounded, generic information transformation before its first experimental exposure, based only on the existing learned evidence and intrinsic five-channel body model. It may use the previously studied compact personal-distress head, but its original action-agnostic regression cannot be falsely described as an action-conditioned counterfactual predictor. Specify a truthful action-sensitive source and a negative control for unknown action histories. Existing native effect predictions must not simply be renamed as a novel computed benefit.
3. **Usable, not externally recommended.** The optional resulting prediction may enter only the existing generic consequence-estimation interface for *legal candidate actions*. Native `Mind` keeps its genome, distress function, action set, financing and final selection authority. There is no action preference inserted and no forced use of a prediction. A missing, unreliable or unaffordable readout falls back under a *predeclared* neutral rule without an oracle. Any aggregation, uncertainty rule, replacement precedence and exact estimator code must be source-locked before a new source; choose none by inspecting the old outcomes.
4. **Meaningful intervention.** The software admission gate must show at least one constructed, non-World, first-person-consistent state in which the readout genuinely changes the native option evaluation *when visible*, while an identical paid-discard run cannot consume it. This is a structural sensitivity check only, **not** a quota for favorable living choices or a reason to tune source seeds.

The scientific treatment is **visibility of the genuinely computed personal result**. The comparator computes it too and physically pays for all actual operations, but that result must not enter action scoring, persistence usable by the controller or any other path that could influence choice. Neither arm receives an observer score, chosen action or information about unobserved ecology.

## 3. Prospective event and phase chronology

**Pairing is a future design choice, not permission to copy or roll back an experienced living Mind.** A prospective paired unit would use separately born, index-scoped organisms assigned to `VISIBLE` and `PAID_DISCARD`, with predeclared equivalent newborn genome, WorldSpec, life seed and independent pair identity. They follow ordinary, uninterrupted lives. Pair-to-pair ecological independence must be justified separately; identical seeds inside a pair are not independent populations.

Before any experimental run, fix the first eligible opportunity from observed *past* history and native affordability, not from later action/outcome success. Preserve **all assigned pairs** including no funded readout, no candidate distinction, no subsequent action, terminal and right-censored paths.

- **Pre-exposure / t0.** From a currently real, personally learned state, freeze complete source and genotype digests, source origin, body, past memory/effects provenance, RNG state and first action already selected by ordinary native `Mind.decide`. Any optional computation must be admitted *before it runs* by the native `CognitiveBudget` in energy **and** vigilance, reserving the already selected motor and all real bookkeeping. Both assigned arms perform and pay the same actual algorithm and output count, then only `VISIBLE` may retain a **controller-usable** readout. `PAID_DISCARD` must demonstrably suppress this channel, not skip an expensive model inference and still claim payment.
- **Original t0 settlement.** Execute the original action once in each *separately born* run, settle actual `World` and paid outcome-learning phases, and seal the `POST_PAID_LEARNING` body, death, all costs and optional no-funding status. Before any informational use, matching initial states and actual t0 receipts must agree; if they do not, classify a transport/confounding failure, never an informational advantage.
- **Next real first-person opportunity / t1.** Seal the actual new perception, real candidate set, admissible information availability and any *new* readout/inference cost before the native decision. Both arms must execute and pay matched optional computations at this first exposure, including forecast construction, reading, bookkeeping and any copied state. The visible result may affect native consequence prediction; discarded information must remain unusable to choice. Freeze the *actual* living `Mind.decide` action, parameter, work receipt and chosen physical inactivity `None` distinctly from `attendre`. Detached options are never actual actions.
- **Actual t1 settlement.** Execute the committed t1 action in each arm's own World and seal native decision/body/learning receipts, final `POST_PAID_LEARNING` state, resources, chosen action and terminal cause. Compare only factual outcomes. Do not simulate an unexecuted alternative and call its body an observation.
- **Missing opportunities.** `TERMINAL_BEFORE_NEXT`, `NO_FUNDED_READOUT`, `NO_DISTINGUISHABLE_CONTENT`, `RIGHT_CENSORED` and `SOURCE_OR_RECEIPT_FAILURE` are distinct. No postmortem decisions, replacement lives, zero-imputed forecast scores, repaired generation or deletion from assigned denominators.

The existing `NextActionPairCustody` syntax from #1305 is the *starting point for the ledger*, not its independent authentication. Extend/review only if necessary for actual source originals, a mechanically verified readout-to-native-Competition delivery, and separately sealed t1 execution. Never set its currently false independent-verification flags to true based on user-supplied hashes alone.

## 4. Comparator and cost isolation

| Arm | Personal source & extra computation | Real energy/vigilance debited | Computed result used by living decision |
| --- | --- | --- | --- |
| VISIBLE (primary treatment) | Same frozen personal model, actual training and readout | **Yes**, before execution; native receipt | **May** inform generic consequence estimate |

| REFERENCE / NO-OPTIONAL (diagnostic only) | Reference P1.3; optional work not run | No fabricated optional charge | No new readout |
| RANDOM-CONTENT / NO-LEARNING (possible later ablations) | Must use independently predeclared actually executed count, origin and algorithm | Actual native cost, not equal-mean fiction | Only under a separately frozen, cost-matched question |

The third/fourth rows **are not approved additional scientific arms**. Including them would require their own exact frozen plan, power/resource accounting and index-scoped authorization; they cannot be opportunistically added after seeing VISIBLE vs PAID_DISCARD.

- Reconcile actual host operations and peak copied memory with declared `CognitiveWork` categories, using the compact-copy findings under [#1283](https://github.com/josselin-orta-lab/individual-zero/issues/1283). The earlier paid-discard path once performed **4 versus 5** forecast calls despite equal model billing; regression must reject such hidden asymmetry.
- Distinguish invariant fixed pre-exposure work from naturally different **later** action, learning, sleep, food, inactivity and cognition costs. Do not force later parity after the treatment legitimately changes behavior. Track sleep-mediated food depletion and forgone future learning; two-currency receipts alone do not cover every consequence.
- Runtime seconds, wall CPU and traced Python bytes are measurements, **not calibrated physiological joules**. An accepted tariff needs explicit conversion assumptions, sensitivity analysis, no uncharged memory copy and a native motor-reserve proof. If it is not calibrated, the result remains a *model-tariff* experiment and cannot claim general real computational affordability.
- Rejected budget → no computation and no phantom debit; no motor-reserve theft; no work after terminal status.

## 5. Outcomes, causal claims and planned analysis

**There are two non-interchangeable gates.**

**G1: actual information-to-choice mediation, not necessarily beneficial.** Across *all* prospectively assigned independent pairs, report denominator and counts for: actually delivered versus physically discarded, native readout consumed, same/different **actually executed** next action+parameter, next opportunity unavailable, no funding, non-exposure, terminal and censor. A positive mechanistic observation requires authenticated readout delivery and a causal treatment contrast, not merely an observer score, a changed hypothetical action or `values`-vector norm. A zero actual divergence can be a conclusive negative for that particular mechanism under the frozen design.

**G2: net lived bodily value, not just prediction quality.** Freeze before source opening:
- primary **intention-to-treat, paired** bodily estimand across all assigned independent units, in inherited bodily distress/return units with native post-paid-learning phase and explicit terminal and right-censor handling;
- one fixed post-exposure horizon or restricted-time functional, precise treatment of death before the next decision and any necessary terminal accounting convention, a robust confidence/uncertainty method and decision threshold, all defended independently (not tuned to P5, 80/81 or 24-pair observed results);
- secondary survival, lived duration, per-channel food/water/energy/vigilance/integrity changes, actual total cognition, lost learning opportunities, sleep/food transfers, inactive fraction and adverse ecological strata, without favorable survivor-only conditioning;
- proper prequential scoring of **forecasts frozen before actual outcomes**, e.g. squared loss only when the forecast and the actual inherited `-Mind.distress(Mind.feats(post_learning_body))` / terminal `-d_max` target have exactly the same phase and meaning. Report unscored windows and action-specific-history absence; never score missing future as zero.

Estimate the randomized treatment's **total** effect, including extra costs and subsequent motor consequences, before any exploratory mediation decomposition. Action difference is neither necessary in every individual nor sufficient to claim improved survival. A t1 bodily advantage caused by a tariff mismatch, ecological leak or unequal learning is a defect, not an informational discovery. A negative G2 after a positive G1 is a scientifically useful *adverse* result, not a reason to rewrite the objective.

No artificial reward or alternate action enters the individual from this analysis; all estimands and statistical code are external observers.

## 6. Source, independence, falsification and evidence custody

Before **any** new scientific World, a separate prospective preregistration must specify and freeze:

1. **Unique untouched source:** independent ecological sampling frame, family definitions/weights, independent unit and cluster level (including genetically correlated lives), deterministic sampler protocol, exact new world/genome/life index namespaces with collision audit and disjoint DEVELOPMENT / selection / validation / reserve; ideally at least eight genuinely independent genetic populations for a claim of generalization under the standing Stage-0 plan, but that minimum is **not** a power calculation.
2. **Exact prospective contract:** one chosen candidate algorithm and integration point, complete code SHA + source/transport fingerprint, genotype/probe versions, physics, price conversion, t0/t1 phases, arms, prior eligibility and opportunity rule, all outcomes, sample size/power/resource cap, no-funding and terminal categories, planned uncertainty method, multiplicity and independent review. None is selectable post hoc from opened worlds.
3. **Tamper/fail-closed checks:** forged/missing originals, swapped or reused indices, future-label leakage, action tags incorrectly imputed to the replay buffer, source/delivery mismatch, mismatched actual operator counts, forged energy/vigilance or sleep/learning receipts, unprepaid inference, extra observer computation reaching Mind, missing t1 execution, `None` changed to `attendre`, terminal-then-action and altered preoutcome SHA must block the analysis claim.
4. **ADR-0017 G/R custody:** run full-scale sealed engineering transport with the **exact future source**, authorized separately as applicable; then separately generate all approved scientific original lives (G), seal their compressed and uncompressed SHA-256 manifests **before** reduction (R), use blind bounded reduction repair and never re-open a failed generation panel or previously used study indices. 5. **Specific owner authority:** a newly dated, explicit, index-scoped approval tied to the exact source, sample count, horizon, arms, family and claim is required. The completed DEVELOPMENT 80/81 lift, broad autonomous engineering delegation and this documentation PR **grant none**.

**STOP CONDITIONS:** If the only information gain is passive predictive loss, if delivered information cannot enter a legal action evaluation, if comparator execution/payment is not actually equal, if original records are not authenticated, if independently sampled pairs are unavailable or if the native cost cannot be calibrated/defended, record the specific negative/blocked gate.
