# I3 Stage 2.1: prospective next-decision replay-content readout

**10 November 2026. Engineering-only prospective design before any new public technical life. This is not a new scientific cohort or a replay-content policy.**

## Motivation and falsifiable question

The closed first-realstate 24-pair cohort demonstrated a local learned-value change from priority-vs-random memory content on **17/24 assigned units**, with seven no-fork nulls. This does not show whether changed learned values change what the individual would choose, or improve the accuracy of its forecasts.

At the **first genuinely funded** random-content replay whose selected memory set differs from TD priority, capture the same actual pre-replay personally learned state. On **two external detached Mind copies**, apply equal numbers of actual P1.3 TD replay updates for (P) historically TD-prioritized memories and (R) true life-seeded HMAC-random eligible memories. The living individual executes **only R**, its original unchanged policy. At the **next actually observed live first-person capture**, compare what the detached P and R minds would each select when supplied the **same current perceived Body/cells and separate same physical-budget law allowances**.

**Primary technical readout**: did the two detached minds choose different admitted actions/parameters or decision option? Also count actual replay forks that lack a following live decision, action-equal/option-different events and no-fork events. A cloned software decision is not an action, World step, second birth, charged individual cognition, causal mediation or survival counterfactual. The R shadow choice, option and work must exactly match the next actual living choice; any mismatch invalidates the entire engineering rehearsal.

**Secondary restricted score**: only when P and R select the exact same action and parameters and that action is actually executed without terminal death, evaluate a bootstrapped TD residual on both detached minds against the exact observed post-action body. This is a *model-dependent Bellman residual*, not a proper calibrated prediction-loss score, independent utility of a memory, matched-budget survival, or a future oracle. Never compare TD residuals between different actions against only R's realized outcome. If action differs or death intervenes, report null/censored rather than inventing an outcome for P. No hidden World resources are inspected.

## Interpretation

The strongest potential result is that two identical actually trained states, changing only which personally obtained memories are replayed, can yield a different **next hypothetical action** when shown the *same next perceived situation*. That does not say which action produces superior survival. A subsequent scientific test, if justified, must predeclare a genuine out-of-sample prospective prediction target derived only from the individual's experienced events, with model costs, no future-information leakage, a proper scoring rule and no hand-coded water seeking. The present shadow residual is inadequate to certify utility or predictive calibration. I3 remains Stage 2.1 and unregistered; Stage 2.2/selection/reserve are blocked.
