**Freeze before source code, 12 November 2026.** Baseline main `31c9b405216d83800b25469d4d1730708a9c29b5`, branch `research/i3-stage2-prequential-prediction-reliability-20261112`. This is an **engineering-only, no scientific-cohort** test of a different gap from frozen E3: E3 estimated a nonlinear expected consequence from an action-indexed distribution; this diagnostic asks whether the *existing native count-based uncertainty* is accompanied by an honest, causally **preoutcome** record of actual errors in the native action-effect forecast. It must not be represented as a new source of actionable information until a distinct prospective C02 gate is later satisfied.

## Scientific motivation and falsifier

[EffectsModel](../../../modules/mind.py) advertises a running mean/variance, but stores effective count, five-channel running mean and integer count only, no observed forecast-residual distribution. Its `predict(key)` uncertainty is `1/sqrt(1+n_exact_key)`, or 1 for an unsupported exact key even if a fallback mean is available; this is a **count-based proxy**, not an independently evaluated prediction-error confidence. Prior frozen E3 [result](E3_NATIVE_PAID_BRANCH_DELIVERY_RESULTS_2026-11-11.md) changed one option score but 0/2 native motors; **do not** retune E3 or infer a cause of that null from missing E3 score vectors. The new question is whether first-person native effect predictions can be timestamped before a native chosen action and scored on its genuinely observed subsequent body at the same training-target phase, with count, source and missingness intact.

**Falsifier:** any target seen before forecast freeze, modified original action or policy, unpaid observer work represented as individual's work, wrong original effect key, forged outcome, invalid two-currency native receipt, lack of exact first-person seed/capture custody or lost terminal/null/no-learning entries => SOFTWARE_DEFECT. A high/low MSE, lack of variation, missing action history or uninformative count bins is a valid **negative/inconclusive** observation, never to be selected away.

## Decision

Pass means only `PREQUENTIAL_FIRST_PERSON_EFFECT_CUSTODY_PASS` (native first-person forecast/actual-body custody exists under current self-directed motor). It does **not** mean the uncertainty is calibrated, that the mind decides whether to pay computation, that action changes after new information, that extra host CPU is physically priced, or that survival/generalization improves. Negative/inconclusive uncertainty calibration may guide a later separate action-relevant hypothesis, but cannot authorize a new heuristic based on count or E3 retuning.
