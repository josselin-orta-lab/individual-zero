## Hypothesis and predeclared engineering gate

The compact head was algebraically equivalent to the legacy detached head
on 48 synthetic fixtures, but its **new** explicit operator-category work
envelope has **never been charged in a lived reference I3**. Test whether
exactly that new declared amount can be preauthorized from actual
first-person energy and vigilance, physically debited in native
`World.step` *before* the motor effect, and trained only after the
authorization, without changing the already selected action, living
learned state, RNG, World or birth genotype. At the next actual outcome,
score a prediction SHA-frozen before that same factual step.

Fail closed if any paid arm is missing the actual outcome, if native
`World.step` differs from the preauthorized work/bill, if any action,
full physical trace or physical accounting differs across equally paid
branches, or if fewer than all 9 eligible forecasts are actually scored.
A null or death remains recorded, never imputed as success or silently
replaced. The technical result is NOT a scientific GO, even if all gates pass.

## Fixed engineering sources, four arms per seed

Use exactly the **new technical life seeds** `940041, 940042, 940043`,
`genome.midpoint()`, existing `dev_open_field()`, horizon 80;
for each seed, three **paid** arms `priority`, `random` and `discard`
plus one `reference` arm with no extra head (12 temporary 80-step
engineering simulations, no independent ecology). The reference is
**not a cost-matched forecasting control**. Its role is checking that
the live motor choice at the first paid opportunity was already
selected before the added work, not interpreting later differing
physical trajectories as an information effect.

At the first first-person decision with >=6 personally lived entries in
the current `Mind.buffer`, and only after the original `Mind.decide`
returns:

1. Read only memory **count**, actual first-person `capture["body"]`,
   chosen action/parameter and the same native decision allowance.
   Obtain `work_envelope(n,k=3)`: `CognitiveWork(cycles=7,
   memory_items=4*n+6,replays=3)`. Preauthorize with existing
   `preauthorize` on the live `CognitiveBudget`, protecting the
   already chosen motor energy. On failure: **zero** compact head
   operations, zero extra work, clear `NO_FUNDED_FORECAST`.
2. Only **after** a successful reservation, make the compact immutable
   personal memory snapshot. Compute BOTH original TD-priority index
   ordering and genuine life-seed/ordinal-separated HMAC random index
   ordering for **every** paid arm. Compute the same k=3 actual
   direct-outcome updates in all arms. The `discard` control
   computes and pays for all 3 updates but freezes the *pre-learning*
   head's prediction. Never forge free learned computation.
3. Seal a per-seed/mode/step SHA-256 before the next real `World.step`
   including selected actual action and param, personal source snapshot,
   training count and prediction. Return the enlarged **native
   `budget.work`** to unchanged `run_life`. Inspect the actual
   `World.step` receipt and independently verify the full decision
   `CognitiveWork` and both native paid currencies, with zero unpaid
   work. Observer-only hashing and bookkeeping remain explicitly
   **external laboratory instrumentation**, not a production cognition.
4. Score **only** the *actually executed* next-first-person World outcome,
   against original innate `-Mind.distress(feats(after_body))` or
   observed terminal `-d_max`, using squared loss. No alternative
   World, policy-modifying readout, hidden future, invented memory,
   free result, terminal deletion, or post-hoc rescoring.

Within each fixed technical seed, compare every paid arm on
`trace_head`, `evidence_head`, `steps_lived`, `terminal`,
`death_causes`, `actions`, `final_body` and the *full* dual-currency
`cognitive_accounting`. All three paid paths must be identical
in their native physical and decision trajectories. Confirm the
first paid arm's selected **precharge** motor action/parameter equals
the original reference at the same step. Compare observed squared
loss descriptively over all **three assigned** units, including nulls.

## What this does **not** establish

The compact tariff is a **declared cognitive operator-category model**,
not a measured CPU-to-physical-energy conversion. Native World debit is
a real debit **within those existing World laws**, not proof of
calibrated biological or computational efficiency. All three paid
branches use action-agnostic, detached predictions; no predictor controls
a physical action, no action-value counterfactual is observed, and the
three seeds share one deterministic engineering ecology. They are **not**
three independent populations, a scientific birth cohort, survival
noninferiority, learned adaptive value or ecological generalization.
No new scientific World authorization, no Stage 2.2 or registry
activation; `scientific_lives=0`,
`scientific_verdict=NOT_ISSUED`.
