# Stage 2.1: native-choice cost bridge preflight (12 November 2026)

**Pre-code fixed engineering hypothesis.** Baseline main `359ba034bac36f524faad922de91a30593ea3380`. Branch `research/i3-stage2-native-choice-cost-bridge-20261112`. The earlier [actual learning-settlement result](STAGE2_ACTUAL_LEARNING_SETTLEMENT_RESULTS_2026-11-12.md) used a laboratory-fixed `attendre` action, not `Mind.decide`. This new **one-step engineering** bridge asks whether an optional computed-and-discarded cognitive readout can be charged *after a genuinely native decision* and before the actual World/learning payment, while preserving the already chosen motor and all null/refused opportunities. It must **not** be interpreted as a first-person information-benefit or autonomous *choice to buy cognition*.

## Frozen inputs and all-assigned population

Reuse exactly the four frozen bodies from `i3.lab.stage2_readout_learning_affordability.CASES`, unchanged: `energy_boundary`=(0.56,60,60,90,80), `vigilance_boundary`=(5,60,60,90,0.55), `both_funded`=(5,60,60,90,5), `optional_denied`=(0.49,60,60,90,80). Two arms each: `reference` (no extra readout), and `optional_requested` (attempt one extra readout). Exactly **4 x 2 = 8** one-step **engineering Worlds**, no scientific lives, independent sample claims, held-out/validation/reserve cohort or researcher-selected favorable context. Each World is 1x1, spawned at (0,0), the same predeclared body, no resource or scheduled World change, original `BodyLaws`. `Mind(midpoint(), 100061)` in each arm; no synthetic `Mind.last` injection, no inherited learning, no fake personally acquired effect.

Call the original `Mind.decide(world.capture(), CognitiveBudget(world.body,world.laws))` **once and only once**, without forcing or replacing action/param. A null motor due to insufficient cognition, no scored option or controller rejection is a **valid assigned null**: retain it with its real paid decision work, perform no optional action-specific readout, do the resulting native `World.step(None,None,work)`, and mark next learning unavailable. Do **not** tune a body, gene, seed, local World or score to obtain an action.

When action is native and admitted, record action/param and full source/allowance state *before* optional work. If `optional_requested`, use the existing `_authorize_optional` from the four-case model (motor reserve protected) to request `proposed_readout_work(0)=CognitiveWork(cycles=6,memory_items=48)`. **Only if actually authorized**, run the existing `passive_readouts` on the chosen action using no future World data; explicitly **discard its computed information**, and preserve the Mind source and both native RNG states. If optional work is denied, it must produce no readout and no additional bill. The readout is never fed back to `Mind.decide`, `Competition` or `Action Control`; it cannot alter the already emitted motor.

Execute *exactly one* `World.step(action,param,allowance.work)` per World, and account for both energy/vigilance via the actual native receipt. On a living, action-bearing result, run `Mind.observe_outcome`, then the native `Mind.prepare_learning` with fresh post-step `CognitiveBudget`. If granted, call `World.pay_cognition` **before** `Mind.learn_from_outcome`, matching replay counts; otherwise zero payment/no learner update. Preserve all five body channels immediately post World and post learning. No second decision, no future action, no resurrection.

## Predeclared controls and outcome classes

* In every same-body paired case, **native action/param, native pre-optional `CognitiveWork` and option choice information must match exactly across arms**. Any failure is a violation; no trial is discarded. A native action may be null. No novel personal-information signal is expected from the empty first-step memory.
* Pair may be `NO_NATIVE_MOTOR`, `OPTIONAL_DENIED`, or `OPTIONAL_PAID_AND_DISCARDED`. Every case counts in the denominator. The **number of lost subsequent learning allocations is a measured output, not fixed to two**: the previous two were found under a *different forced-action protocol*. Never retune after seeing the result.
* In all eight arms, the native World decision receipt must reconcile full energy/vigilance payments and `World.step` count. The actual native learning payment/learner execution must follow `prepare_learning` and agree with zero/paid receipts. Tests must fail on forged or unpaid receipts, unfunded reads, postmortem learning, source/RNG mutation, and mismatched pre-optional motor or decision work.
* When optional work is denied or no native motor exists, actual immediate and post-learning bodies should be identical across arms for that same pair. In paid pairs, any difference is a **cost-only intervention**; it is not adaptive policy benefit or evidence of a naturally selected metareasoner. A null outcome is a valid observation.
* Reports distinguish `World.step` native debit, optional computed operator, and subsequent `World.pay_cognition`. Laboratory SHA and audit display are observer-only, unpriced host work. No invented CPU-joule conversion.

**Stop rule:** `NATIVE_CHOICE_COST_BRIDGE_PASS` only if all assigned pairs satisfy authority, accounting, source and learning invariants, even when there is no action or no optional funding. A fully null panel must be labelled **`NO_ACTION_MEDIATION_OBSERVED`** and cannot be used to claim survival cognition; an invariant violation is `SOFTWARE_DEFECT` and blocks merge. No tuning to produce a positive event. The scientific verdict remains Stage 2.1 `NOT_ISSUED`. The open scientific C02 gate still requires **distinct first-person information** that changes a native decision against genuinely equal *executed* and paid `VISIBLE/PAID_DISCARD`, which this cost-only study does not supply.
