## F1: causal temporal target ambiguity, preregistered

The reference I3 runtime has two potentially different bodily records:

1. `IMMEDIATE_POST_WORLD`: `before_learning = result["body"]` directly returned by the single actual `World.step`. It already includes the *decision* cognition bill and physical action.
2. `POST_PAID_LEARNING`: after `Mind.prepare_learning` authorizes an additional `CognitiveWork` on a *new* `CognitiveBudget(before_learning, world.laws)`, the native `world.pay_cognition(learning.work)` debits both energy and vigilance; then `result["body"] = world.body` is fed to `Mind.learn_from_outcome`. The learned `EffectsModel.observe` stores the delta from the *original before-decision body* to **this post-learning body**, rather than the earlier `World.step` result. This is not an extra World tick. If learning cannot be funded, the bodies coincide; if the individual is dead, no outcome learning occurs, and both bodies coincide.

**Primary proper scalar target, frozen now:** after the *entire native paid decision + motor + allowed learning phase*, i.e. `POST_PAID_LEARNING` `-Mind.distress(Mind.feats(body))`, or original `-d_max` for **observed actual terminal**. This matches the effects-model state update semantics and the final `run_life` record. **Secondary diagnostics**: the earlier, distinctly named `IMMEDIATE_POST_WORLD` scalar, with explicit target difference. Neither target may be silently substituted, mixed, or generated from a counterfactual World. The same three already proposed passive action/global/persistence forecasts are *frozen before either phase*. No future label or learned statistic after the outcome may enter a prediction.

**Falsifier:** fixed synthetic phase fixtures where immediate vs post-learning bodies differ ONLY in the correctly modeled native energy/vigilance learning debit should yield *different* target scores whenever at least one affected channel is in distress. When the learning bill is zero/denied, or terminal was genuinely observed, both phases must produce the SAME target. An observed terminal penalty must be `-d_max` at both phases, never imputed as zero. An illegal phase jump, altered action, mismatched bill, tampered seal, post-learning body with food/water/integrity changed, artificial positive energy from a debit, double settlement or unobserved/horizon result reported as zero loss must be rejected.

## F2: preliminarily costed passive readout, before ANY optional computation

The #1294 helper `passive_readouts` reads existing **learned** reference `Mind.effects.stats` and the inherited `theta/p/w`, scans the native four-field `Mind.buffer` for source integrity, evaluates three body projections and inherited distress readouts, and performs *external laboratory-only* SHA-256 provenance hashes. The source effects were paid when actually learned by native `run_life` in a real authorized life; the #1294 synthetic effects were **never** paid and are not biological data.

Specify a **new engineering-only proposed** `CognitiveWork(cycles=6, memory_items=48+n, simulated_steps=0, replays=0)` envelope, where `n` is the actual number of eligible personally stored native four-field memories, `0<=n<=m_max<=512`. This is a declared worst-case **model-category** service reservation for native effect lookups, two learned 5-vectors, three body projections, three five-channel innate distress readouts, source/temporary memory service, and an O(n) native memory-arity check. It is NOT calibrated to host CPU instructions, hash bytes, allocator behavior, actual measured joules, or organism survival. External SHA/hashing remains **laboratory measurement only**, not a charged endogenous capability. No sorting, HMAC selection or replay occurs here.

**Admission gate:** after the ORIGINAL `Mind.decide` has already selected a non-null actual action/parameter and returned its own base `CognitiveBudget`, verify that `budget.body` exactly matches that first-person body and `Mind.last` records that same chosen action, param and before-body. A null motor choice or missing original action evidence yields an explicit unpriced `NO_SELECTED_ACTION` slot (never a forced wait/sleep). Verify finite body and buffer capacity before any optional readout. Obtain incremental cost from the UNCHANGED native `BodyLaws`. If remaining energy/vigilance cannot pay it **while still reserving energy for the chosen motor action**, return a `NO_FUNDED_READOUT` receipt with **zero optional readout calls**, unchanged allowance and unchanged source. Only AFTER successful `CognitiveBudget.try_spend` may the external laboratory code call `passive_readouts`, freeze its three forecasts and source/selection SHA, and declare the expanded native work ticket. In this software-only study, `try_spend` is **authorization within the model**, not evidence of actual `World.step` debit. A pure `debit_cognition` calculation may verify the expected two-currency bill for synthetic tests, but there is no live World. Never call it `actually body paid`.

**Outcomes:** score only a separately phase-tagged **synthetic** pair of observed future bodies, after checking the SHA-frozen action, param, work and modeled receipts. For learning phase, use only the unchanged `debit_cognition(immediate_body, laws, learning_work)` as a strict pure mathematical verifier: nonterminal `PAID_LEARNING` requires nonzero, affordable work, exact post-body and both paid receipts; `NO_FUNDED_LEARNING` requires zero work and identical bodies; `TERMINAL_NO_LEARNING` requires an actual nonempty terminal reason, zero work and identical bodies. A fabricated positive-learning receipt without full energy and vigilance, phase replacement, missing earlier World observation, or a forged after-body is rejected. The synthetic score should disclose both targets, the precommitted **primary** phase, and the loss for all three modes under both phases; score once only. Do not allow an exposed target to change the next choice or learning.
