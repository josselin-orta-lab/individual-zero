# Stage 2.1: World-paid private previous-error uncertainty into native decision, cost-confounded engineering STOP (12 November 2026)

**Exact-source verdict: `PAID_RESIDUAL_READOUT_STOP_NATIVE_COST_CONFOUND`. Scientific Stage 2.1 remains `NOT_ISSUED`.** This is an adverse, finite **DEV-only software result**. It does not establish native motor mediation by extra information, autonomous decision to purchase computation, a survival benefit, population generalization or the end of Stage 2. ## Frozen operator and payment behavior

- The original `Mind.decide` retains option creation, native learned effect **mean**, first-person perception, needs, existing curiosity/risk scores, `Competition`, `Action Control`, decision randomness and all motor authority.
- In the lab subclass, `Mind.simulate` issues a **provisionally modeled** `CognitiveWork(cycles=1,memory_items=2*n+2)` quote *before* reading any n prior own-error records for each relevant native predicted action step. Both `VISIBLE` and `PAID_DISCARD` **really scan the same history under the same readout operator bill**. They both calculate the same one-pseudorecord error estimator and bounded `sqrt(risk/(1+risk))` transformation. VISIBLE returns that value only when same-action support exists, while PAID_DISCARD returns the original `EffectsModel` uncertainty. No memory/outcome oracle and no action-specific behavior exception.
- When a native action has been selected, an additional actual native prediction is authorized/paid in cumulative `World.step` before the motor; native outcome learning is separately paid. Additional prediction-error calculation and append to a **per-Mind experimental private error-history list** is authorized and actually paid by `World.pay_cognition` BEFORE it runs. Thus historical own-error records are not supplied free from laboratory logs in this experiment. The supplementary *decision to buy* all these computations is still made by the laboratory, not by the individual.
- Equal executed **optional source-read** work before divergence does **not** ensure equal **total** native calculation: changing an uncertainty input can change the number of normal, body-paid `Competition` cycles without changing the final motor.

## Scientific consequence and stop decision

The essential obstacle is not merely storing an own-error memory or financing its scan, both of which were technically exercised. An additional signal can influence **how long the existing native Competition works**, even if it does not change its selected motor. This indirect change in bodily expenditure is itself a physically meaningful consequence, but it **confounds** any naive VISIBLE-versus-DISCARD comparison that assumes equal total computation after an information-dependent native controller.

**Decision:** do **not** tune the source, convert this cost difference into an assumed beneficial adaptive mechanism, claim action mediation or reopen E3. Retain P1.3 unchanged and keep the result `STOP_NATIVE_COST_CONFOUND`. Before any new scientific-life protocol, either (a) define a prospectively fixed **cost-mediation estimand** which accepts unequal endogenous Competition costs and evaluates their complete effects as part of the treatment, with an independently powered ecological design, **or** (b) separately design a genuinely equal-all-in-work causal comparison without overriding native action, and prove its engineering feasibility **before** new sources. Neither option is authorized or justified by the present DEV grid. Continue independent methodology review and tariff calibration, and leave Stage 2.1 `NOT_ISSUED`.

**No GO:** no engine registration or stage promotion, no new independent source index, no scientific cohort, no rule instructing the individual how or when to think. Original E1/E3 candidate negatives remain sealed.
