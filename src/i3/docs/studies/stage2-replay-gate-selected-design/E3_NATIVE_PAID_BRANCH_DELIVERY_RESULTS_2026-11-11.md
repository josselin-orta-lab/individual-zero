The arithmetic mean of those **native bodily-distress simulation values** becomes the visible score, with original uncertainty and bonuses unchanged. It is a simple equal-frequency recent-outcome model, not a new policy, oracle or designer-specified action preference.

The **PAID_DISCARD** comparator performs all those same source scans, view constructions, branch simulations, reductions and actual native `CognitiveBudget` work, but returns the original mean-model score. Both branches precheck a conservative cost ceiling and preserve the maximum existing motor energy reserve; the quote itself is NOT falsely charged as real work. Both storage and query costs are **modeled energy/vigilance currency**, not measured real CPU joules or an actual (World.step) physical debit. If memory is absent, an actual paid missing-support scan occurs and cannot synthesize favorable effects.
