## Personal-history handoff

The innate expectation is a **first-contact disposition only**.

As soon as the ordinary P1.3 EffectsModel contains any personally learned
`("boire",)` effect, positive or harmful, the policy stops consulting omega.

This guard deliberately uses the ordinary learned effect rather than requiring
the auxiliary branch ring to retain the sample. If physical branch storage was
unaffordable, an actually lived drink consequence still counts as personal
experience and must suppress the inherited prior.

After that handoff:

- the existing personal frontier-belief path is used;
- exact/same-action empirical branches remain paid;
- omega is absent;
- a harmful personal drink history may make water non-actionable;
- carried-food and all other personal-effect paths remain omega-free.

Thus the gene cannot continuously bias a learned action merely because the
individual inherited optimism or pessimism.
