decision -> physics -> learning -> storage -> next-decision transitions.

This gate asks only whether the repaired runtime can maintain coherent custody
through longer, consecutive lifecycles. It is not a behavioral experiment.

cognitive prices, seeds, horizons, policy rules or a later scientific margin.
