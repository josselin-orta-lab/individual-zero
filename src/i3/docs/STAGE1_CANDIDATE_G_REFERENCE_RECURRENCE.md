## Why Candidate-G

The frozen Candidate-F/omega architecture is rejected: 0/240 validation
survivors versus 82/240 for P1.3. The later 54/55 diagnostic implicates both
computation cost and changed policy, while exact mediation remains unresolved.

Candidate-F also bundled architectural changes that are not logically required
by the Stage-1 information hypothesis:

- simulation mode changed from P1.3 `reference` to `candidate_f`;
- projection accounting changed from `chunk_end` to
  `event_local_quadratic4`;
- first-contact future availability did not consume the separately implemented
  personal recurrence memory unless explicitly overridden;
- inherited omega supplied a first-contact expectation.

Candidate-G asks a smaller question:

> Does the existing information mechanism become decision-relevant when future
> opportunity is estimated only from personal recurrence, while the P1.3
> simulator/projection is left unchanged?

There is no omega and no new genome field.

## Existing substrate only

The characterization composes only already merged components:

- P1.3 `Mind`, `simulation_mode="reference"`,
  `projection_accounting="chunk_end"`;
- fixed paid branch memory;
- `OpportunityRecurrenceMemory`;
- `paid_water_personal_recurrence_value`.

No runtime policy or new cognitive equation is introduced.

The recurrence fixture contains personally observed water-onset gaps 2, 6 and
10. Its horizon-dependent probabilities are therefore 1/3, 2/3 or 1.0. Missing
support would remain unknown, exactly as in the existing recurrence contract.

## Frozen software grid

Exactly 80 states:

```text
5 single-channel deficits
x 4 levels: 20, 30, 40, 50
x 4 horizons: 4, 6, 8, 12
```

All other body channels are 80.

Every state is evaluated under the same fixed personally learned effects and
recurrence history. No world, life, seed search or adaptation occurs.

The report retains every selected and declined state, including:

- deficit channel and level;
- horizon;
- personal recurrence probability;
- information value;
- trial advantage;
- target-node choice;
- actual work and common forecast ceiling.

## Falsifiers

Hard invariants:

- R0: exactly 80 states;
- R1: reference simulation/projection only;
- R2: every future-opportunity probability comes from paid personal onset
  recurrence;
- R3: actual work stays within the complete common ceiling.

Decision-boundary characterization:

- R4: at least one epistemic trial is selected and at least one state declines;
- R5: no selected trial occurs in a state whose only imposed deficit is outside
  water.

R4/R5 are not CI-success requirements. A negative behavioral result is a valid
scientific falsification and must be reported without changing the fixture.

## Interpretation

A pass is only **capacity evidence** for a smaller architecture. It would
authorize the next software step: an opt-in live Candidate-G policy preserving
P1.3 projection, repertoire, Competition and Action Control while consuming
personal recurrence.

It would not authorize a development world, Stage-1 gate, I3 registration or
Stage 2.

A fail means the reference-projection recurrence mechanism remains
decision-irrelevant on this fixed grid. Do not reintroduce omega, change the
projection or tune recurrence probabilities to make it pass.
