# G1-LAB: NON-LIVING integrated research

Authorized by [ADR-0005](../../../docs/decisions/ADR-0005-authorize-nonliving-integrated-g1-lab.md). This is a disposable, internal, single-SQLite research demonstration, **not** an I2 runtime, real motor permission, born identity, Scheduler, or M11.

Run `PYTHONPATH=src python -m i2.lab.integrated_loop --scenario all` for independent fixed-prior and observational laboratory comparisons. No I1 code is imported; `engine.json` and registry remain inactive. Living G1-LIVE still requires independent reviews (#662).

[ADR-0006](../../../docs/decisions/ADR-0006-evidence-grounded-aversion-reappraisal.md) corrects the scientific interpretation: observational recovery and adverse worlds are indistinguishable without a new EAT or perceptible cue. The stale +9 revisit rule is a researcher-authored comparator, not a default natural exploration drive. See [source-pinned research analysis](../../../docs/research/studies/i2-g1lab-aversion-reappraisal-2026-11-01/README.md).

[ADR-0007](../../../docs/decisions/ADR-0007-need-nutrition-aversion-scientific-design.md)
approved the scientific framing, *not* execution. Later the owner accepted
the exact v1-r1 protocol blob `a279067fbfd21f02ee4aa7854509c19f12cfbb62`
and authorized **one** 4-cell x 4-arm study in [issue #662](https://github.com/josselin-orta-lab/individual-zero/issues/662#issuecomment-6561384748).
The opt-in, researcher-engineered policy is in `need_aversion_policy.py`,
with source implementation in PR #814 and the
[completed 16-arm execution report](../../../docs/research/studies/i2-g1lab-need-aversion-protocol-2026-11-01/execution-report.md)
in PR #815. The run recorded 128 modeled captures, varied actual synthetic
UC and a high-energy aversive tie/abstention, but **no demonstrated natural
autonomous learning or survival benefit** over the fixed-prior control.

The original prospective protocol and approved numerical lock are retained
unaltered for source provenance, including their historical NOT_AUTHORIZED
wording. The separate owner authorization is now **exhausted**: do not tune
or rerun another exploratory factorial from it. The study neither enables
the ordinary I2 runtime nor authorizes birth, motor effects, independent
M11, living G1 or G3. The next critical step is an independent G1
architecture/science review (#662), not another G1-LAB iteration.
