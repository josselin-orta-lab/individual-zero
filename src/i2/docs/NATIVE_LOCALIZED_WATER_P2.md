# P2 native resource localization: paid access before learned place value

Prospective physical-world slice for [P2 #924](https://github.com/josselin-orta-lab/individual-zero/issues/924),
following owner-approved ADR-0011 and P1 minimal traversable space.

An immutable new native v12 birth parameter `ordinary_water_site`
accepts `None` (default, preserves globally accessible ordinary water)
or a **physical exact P1 site** (camp, passage or source) when
`spatial_world=True`. The born parameter and genesis hash bind the
location; tampering must fail cold audit. A site name does not
promise hydration efficacy, or even knowledge of stock outside the
currently occupied physical place. Ordinary water `boire` is offered,
admitted and cold-replayed only at the born physical site **while stock
remains**. The actual drink gain and degradation laws are unchanged.

This is a *site accessibility primitive*, **not** a learned value,
site-memory plan, discovered route, new body owner or promise that a
resource stays present. No move or return is forced. The pure
two-edge route used for access checks is expressly physics-only,
never evidence of an individual's chosen locomotion. The existing
cognitive Competition still owns every selected action.

The genuine P2 milestone remains a **same-life voluntary paid return**
to an already experienced useful location when a bodily need recurs,
contrasted with learning OFF, inaccessible/stale/ineffective locations,
actual UC and cold replay. Current research-only local born instances
do not establish registered I2, independent M11 or natural learning.
