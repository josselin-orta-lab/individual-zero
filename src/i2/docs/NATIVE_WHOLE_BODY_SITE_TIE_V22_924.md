## Exact mechanism: existing paid competition, no new motor

The P2 v21 target-only `place_return_tie` remains unchanged and selected by default. An additional exact-boolean born flag `whole_body_place_tie=False` can be enabled **only** when existing spatial place-return learning is already enabled and `purpose_followthrough=False`. The flag is included in the same SQLite `native_genesis` signed digest and independently cold-replayed; no second owner, new journal, I1 code or authority is introduced.

When ON, `personally_lived_whole_body_place_tie` uses only the individual's already committed `lived_whole_body_site_consequences` with the body's **current** `assess_needs` pressure. Only personally performed **resource consumptions** (food or water) contribute to a place association; resting/sleeping cannot falsely reward one site because they can occur anywhere. For each previously experienced site, the learned reference is the **mean** signed sum of actual four-channel deltas times today's four need pressures. Concurrent injury contributes negatively; food/water/energy restoration contributes positively only as relevant to today's body, including a full-stomach harmful meal when it is actually observed. Old experiences are evidence, not a promise of a stock, effect or future safety.

On an already positive maximum paid **tie** among at least two offered actions, if exactly one physically adjacent tied destination has the unique highest **positive** experienced need-relevance and the current NativeCaptureReflex state is `NO_PREEMPTION`, add **one experimental point** to that movement score. This is a bounded, falsifiable human-designed hypothesis, not an instruction to move; the existing Competition still selects, Action Control still admits, physical adjacency/UC still constrain. Unknown sites have no site score, equal references do not break a tie, and zero/negative evidence confers no bonus. No oracular safe-site labels, unchosen resource outcomes, new global survival scalar or privileged motor access. The identical old target-only scoring path remains when the flag is disabled.
