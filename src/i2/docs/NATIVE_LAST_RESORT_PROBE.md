# I2 native unknown-probe last resort: local software test

Continuation of ADR-0009 / issue #888. The first-person native life may
expose a **new uncertain collecter affordance** only when its goal has been
reappraised after two personally experienced failures under critical need.
This is not a fixed motor fallback: the ordinary paid Competition must rank
the new candidate and fresh safety still controls any physical admission.
The innate exploration coordinate influences its subjective ranking via
native_scores. No positive payoff or hidden world-state knowledge is provided.

For now the bounded common world defines collecter as a physically costly,
nonrestoring exploratory move: it consumes energy and metabolic resources.
It cannot materialize nutrition, water, location or a new resource. The
first negative collected outcome is available only on the next capture and
is auditable via the existing SQLite transaction and original birth replay.
This makes the current experiment deliberately falsifiable rather than
pretending an effective rescue has already been discovered.

Tests check a critical-water learned reappraisal, an admitted collecter
transition without advance reward information, next-capture experience,
and no-learning negative control. A separate resource-discovery world
with truthful externally resolved outcomes, geography, replenishment and
physical-time parity will be required before any meaningful adaptive
survival or I1/I2 superiority claim. This software increment is NOT
independent M11 custody, I2 activation, or scientific G3/G4 GO.
