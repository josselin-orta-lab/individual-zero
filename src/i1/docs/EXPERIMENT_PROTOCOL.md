# I1: prospective and reproducible experimental protocol

This is a template for **new** natural-I1 investigations, not a declaration of scientific acceptance.

## Research question and preregistration

State the falsifiable capability under examination: for example, whether changing thirst alters option competition under personally visible water availability. State rival explanations including random exploration, stage availability, temperature/body decay, reachability, UC admission and privilege leakage. Set the fixed code SHA, world-preset digest, run budget and observation fields **before** interpreting results.

## Running independent lives

Use `tools/run_i1_world_preset.py --list`; select registered environments in `lab/world_presets/`. Choose unforced newborn lives and separate environment truth from first-person evidence. Report seed, life_id, body and inventory trajectories, actual actions, journal hash, owner changes, UC and terminal status **only when actually recorded**.

The preset `--seed` currently determines a reproducible identity but does not re-randomize a preset's fixed physical map. Therefore different seed labels alone are not independent environment realizations. Do not inflate sample diversity. WAL and M11 custody differ in exposed fields; the observer must not invent missing physical telemetry for M11.

## Controls

- Compare visible and inaccessible resources without injecting an oracle.
- Compare near versus remote water and a no-water negative world.
- Compare constrained passages and open routes.
- Vary needs and temperament only through declared birth inputs.
- Preserve accidental and fatal outcomes in the sample; never restart a life to 'repair' results.
- Include a negative test for every apparent learning or agency result: can the same observed outcome arise from an environment-only change?

## Evidence disposition

| Finding | Minimum documentation |
| --- | --- |
| Software invariant | Exact code/test SHA, test output, negative case |
| Behavior observed | Individual identity, environment digest, step trace, observation provenance |
| Cognitive mechanism exercised | Owner outputs and costs from the *actual* current run |
| Causal interpretation | Alternative causes assessed, uncertainty recorded |
| Scientific conclusion | Independent replication, preregistered controls, adversarial review |

If a trace omits option competition, UC or owner publication, mark those fields NOT_OBSERVED; never infer intent from the final position. Old A2.38/A2.39/H1/H2 runs are historically inspectable but are not current natural I1 reference populations.

## Scientific gates

The current scientific gate remains **not established**. Stage10 nonempty multi-owner publication, robust self-maintenance and distal agency need fresh evidence. Any proposed scientific GO requires explicit human-reviewed protocol, checks and interpretation separate from a green CI.
