# I1 cognitive modules

This directory holds I1's generation-owned cognitive mechanisms (including perception, needs, memory, goal arbitration, Competition, action admission, planning, causal modeling and consolidation support). Individual modules can be **active, dormant, experimental or invoked only through particular Stage boundaries**. A source file existing here is not sufficient evidence that a born individual uses it.

Start from [I1 handbook](../docs/README.md), [current status](../docs/STATUS.md), [Stage ownership map](../docs/STAGES_AND_INTERFACES.md) and [capability integration](../docs/CAPABILITY_INTEGRATION.md). Verify active constructors, owner publication, actual call sites, UC charges, tests and [evidence matrix](../docs/EVIDENCE_MATRIX.md) on the exact commit.

Never infer I0 activation from historical names or copy obsolete models into another generation. Proposed mechanisms must pass their own behavioral and scientific review; failing and negative outcomes remain usable evidence. Cognitive authority does not belong to adapters, Lab observers, hidden world truth or benchmark oracles.
