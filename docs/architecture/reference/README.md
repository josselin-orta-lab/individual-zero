# Architecture reference index (versioned research contracts)

These are conceptual and versioned MVP source documents. **They are not a live-engine registry.** For the running generation use [the registry](../../../config/engine-registry.json), [I1's own handbook](../../../src/i1/docs/README.md) and [I2's proposal handbook](../../../src/i2/docs/README.md). Never infer implementation conformance, scientific GO or engine activation merely from publication of a specification.

## Scope and precedence

- [Conceptual architecture v2 (French)](fr/architecture-v2.md): broader theory and hypotheses, not an executable implementation contract.
- [MVP v1.2.1 (English)](en/mvp-specification-v1.2.1.md): retained historical implementation baseline.
- [MVP v1.3.0 (English)](en/mvp-specification-v1.3.0.md): superseded journal-removal proposal; **not** current authority.
- [MVP v1.3.1 (English)](en/mvp-specification-v1.3.1.md): retains the complete causal journal and independent Oracle/Bench.
- [MVP v1.3.2 (English)](en/mvp-specification-v1.3.2.md): additive Stage 12 goal-result attribution target, without claiming software conformance.
- [MVP v1.3.3 (English)](en/mvp-specification-v1.3.3.md): later additive, evidence-bounded Stage 6 predictive-model **research** contract; autonomous cognitive deployment **not approved**.

Each document states its own normative scope, evidence limitations and precedence. A newer version does not automatically make I1 or I2 conform to it, and the historical versions remain available unmodified.

## Languages and translation

The English documents above are normative within **their historical MVP scope**. French counterparts are informative where the individual specification states so. [English index](en/README.md) and [French index](fr/README.md) list existing texts. The conceptual architecture v2 is available in French, with English translation pending.

Equivalent translations have matching basenames in en/ and fr/, and never create a new technical version. Keep the source-language authority explicit and avoid rewriting older specifications merely to align an index.

## Governance

For architectural generations, [ADR-0001](../../decisions/ADR-0001-strict-generation-autonomy.md) requires separate engine-owned cognition, world, UC and persistence. Source contracts and reproducible experiments have different evidentiary roles. Archived I0 work must not be silently promoted into the active I1 or proposed I2.
