# MVP v1.3.2 subjective goal-agency adoption and implementation checklist

**Status: normative text prepared for protected PR review; NOT code acceptance.**

## Why this is a separate version

MVP v1.3.1 retained full journal custody, M-11 continuity, irreversible mortality and independent Oracle/Bench. Stage 12 §16.1 requires attribution bias, but P-47 §9.6 supplies only prediction-compatible agency comparisons. Issue #110 cannot safely relabel those comparisons as `self/world`.

The new GA-01 through GA-07 requirements authorize a subordinate Action Control *subjective* attribution judgement for a **goal-relevant consequence** with separately committed perceptual cues. They forbid deriving that judgement from the outcome being diagnosed. They preserve both objective truth isolation and honest abstention.

**Important name collision:** `mvp-v1.3.2-dc05-food-safety-semantics-delta.md` is a historical proposal only; it is **not** enacted by this v1.3.2 contract. Issue #89 and Stage 9 scientific NO-GO retain their prior interpretation.

## Implement in small, reviewable PRs

1. **Action Control (GA-02/04):** versioned first-person assessment commitment and immutable judgement; baseline freeze, permitted efference and perceptual cues, one closure, strict life/action linkage, `self/world/unknown/unavailable` distinctions, no P-47 label conversion.
2. **Precommit (GA-03):** reuse `Stage12GoalProgressLedger`; link the admitted goal-motivated command, physical digest, identity and temporal window. Avoid a duplicate goal ledger.
3. **Integration and UC (GA-05):** register positive, deterministic pre-birth costs; charge through Scheduler's existing budget/owners; reject refused work, do not manufacture samples; publish at permitted boundaries, never postmortem.
4. **M-11 persistence (GA-05):** extend *existing* Action Control and Metacognition owner snapshots, schema migrations and authenticated cold-install; test actual `os._exit`, duplicate retries, interrupted/uncertain commit and terminal death.
5. **Metacognition (GA-06):** bounded, idempotent and independently provable join, only after both original source receipts; next-cycle diagnostic visibility, same physical step counts at most once; keep all other detectors stable.
6. **Independent verification (GA-07):** extend Stage12 operator packet and canonical receipt audit, not just presence checks. Reject fully rehashed inconsistent forgeries, mismatched lives, missing sources/charges, wrong time, duplicates, late/no capture and reinterpreted P-47.
7. **Experiments (GA-07):** preregister mixed real lives and a 600-step exploratory campaign, preserve zero/negative data, no imposed commands designed merely to force a favorable statistic, no scientific or operator GO inferred from test green.

## Acceptance barriers

- The new English text is authoritative for the proposal only once the protected documentation PR is approved/merged under repository governance.
- A merged specification does **not** establish that current code conforms: do not announce Stage12 PASS.
- Do not merge PR #147 as a final solution while its fail-closed audit deliberately reports `admitted_pairs=0`; update its audit contract only after a complete versioned cognitive producer and independent evidence join are implemented and tested.
- Explicit Stage 12 operator reception and end-of-project scientific validation remain separate; issue #110 must stay open until the complete chain is experimentally exercised.

## Non-goals

No new top-level cognitive module, no Oracle labels in I0, no reuse of P-47 compatibility labels as a subjective judgement, no physical-world causation claim, no weakened Stage 9 safety boundary, no changed WorldBody physics, no cost-free diagnosis, no snapshot resurrection, no arbitrary lowering of detection thresholds.
