## Hypothesis and strictly bounded opt-in design

Without changing any physical/cognitive fact, option value or budget, an *existing Scheduler ledger* can answer whether the **next sequence of configured UC requests** is fundable. The check is passive bookkeeping (the same constant-size admission check already performed by `CycleComputeBudget.charge`), **not** a simulator rollout, Exploration search, Action Control invocation, causal inference, safety classification, cognitive service call or free attempt at Planning. It cannot grant UC, reserve UC, change costs, evaluate a target, predict a route or preempt a need.

- Add a pure, non-mutating budget affordability query based **only** on the active cycle's validated config, already spent module/total/ordinary UC and the explicit operation costs. Check the same limits as `charge`: module envelope, cycle ceiling and preserved protected capacity. Unknown operations/modules, invalid input types, no open cycle and noncanonical counts fail closed. Validate against the ordinary `charge` path with independent synthetic budget fixtures, including protected capacity. A declined quote must not set degraded mode, alter snapshots or consume an occurrence.
- Introduce `Stage11Config.geographic_capacity_guard_enabled: bool = False`, versioned when enabled. It is allowed only with existing charged geographic preflight and opt-in geography; all previous configs, probes, historical Stage 9, journals and Stage 11 baselines remain **byte-identical** with flag absent/False. Expose an explicit optional flag on the public `build_public_route_runtime` fixture with a *new* version suffix for guarded runs.
- **Only** in Phase-1 Planning, **after** the standard goal planner has already had its opportunity and any funded route search has finished, **before** the canonical 1-UC geographic preflight, when a raw observed adjacent candidate or an already paid observed route exists, quote exactly `("geographic_admissibility_preflight", "planning_build")`. If both can be funded, do nothing: the ordinary charges occur in their normal order and the final Action Control veto is never bypassed. If the 1+2-UC combination cannot fit, withdraw only geographic owner-local offers; emit `stage11_geographic_capacity_deferred` with declared required/available UC and `charged_uc=0`, `canonical_admissibility_consulted=False`, `safety_decision=None`, `no_new_option=True`. Do **not** log a fabricated `compute_charge` refusal, `stage11_geographic_preflight_consulted`, safety veto or nonexistent geographic plan.
- Budget admission uses the **current live Scheduler ledger only**, not later phase-1 Exploration output or hidden WorldBody facts. Previously observed frontier candidates remain frozen before Phase 1. Do not change the physical need plan, goal priority, Competition thresholds, exploration novelty coefficients, world danger schedule, or the meaning of `incomplete_budget` when a real UC `charge` is rejected.
- This is **bookkeeping-based early deferral**, not a claim that preflight itself is free. If the guard declines, it performs no preflight and proposes no plan. If it accepts, a real charged preflight and a real charged build are still mandatory. Charges from *other* modules must obey protected capacity.
- No historical fixture is changed or quietly upgraded. The opt-in must be a separate development-only A/B configuration. The reduced UC consumption can affect later fatigue and choices; preserve and disclose any such differences rather than insisting on equal future trajectories or adjusting thresholds.
