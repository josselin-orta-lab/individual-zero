# A2.32: born-ignorant I1 and first-person learning opportunity audit

**Registration date:** 2026-10-16  
**State at registration:** protocol only. New A2.32 heldout physical lives have not been run or scored.  
**Source:** I1 experimental PR #219 at `5e1522bb18435aa0c65b1c32c617b7323c9829f5` plus the separately registered A2.31 development results. **I0 main remains unchanged.**  
**Purpose:** Determine what the *existing* opted-in I1 cognitive runtime can perceptually detect, subsequently experience, retain and use for decisions. Do not demand anticipation of physically indiscernible death. No new safety prior, experience-injection API, learning algorithm, inference threshold or physical law is implemented in this phase.

## Scientific questions and preregistered interpretations

- **Q1: perceptible but unfamiliar clue.** If there is a **visibly adjacent creature** near a berry target, does a separately opted-in Stage11 local-threat alert record the accessible clue and change an I1 decision? A sensory alert is not proof that a creature will attack, especially in daytime. Seeing a creature before an action is not learning from a past injury. Report preaction alert source and behavioral difference separately.
- **Q2: learnable nonterminal harm.** If I1 actually walks onto an *invisible but nonlethal* danger zone, then sees reduced integrity in a later permitted body capture, does the current architecture emit authentic lived outcome evidence, preserve it in the memory/agency machinery and modify subsequent actions? The cause remains ambiguous (confounded effects possible); neither a harmful transition nor numeric surprise alone establishes that the place is 'known lethal'.
- **Q3: learnable unsuccessful act.** If the first `collecter berry_b` is externally forced to fail, the next real perception can reveal unchanged inventory and still-visible berry. Does I1 adapt on later decisions, or mechanically repeat the previous command? The lab may inspect the forced-failure switch as an outcome label, but I1 must never receive it.
- **Q4: genuinely indiscernible fatality.** Matched physically safe versus hidden-lethal eastern cells present an identical first-person preaction view. No policy limited to that observation can distinguish the two at birth; record whether the forecast and decision are equal, and report deaths and unlearnable first-encounter data without classifying unavoidable ignorance as poor causal reasoning. Any cognitive use of a hidden hazard label is a NO-GO leak.

## Freeze exact test allocation BEFORE running the new cohort

**Population:** 32 preregistered pairs / 64 distinct mortal lives; **eight** pairs per condition, indexed `00`–`07`; **four** conditions (CUE, INJURY, FAILURE, INDISTINGUISHABLE). Every pair uses physically separate WorldBody, independent I1 identity/memory/journal/WAL, same baseline external training artifact fitted on 16 newly executed (8 move E and 8 collect B) physical laboratory worlds. As in A2.31, provenance is **external lab**, NOT lived I1 memory. Only `i1_model_enabled=True` I1 births are used in the decision comparisons; these worlds measure feedback of the existing active model rather than revalidating OFF controls. The A2.31 model-OFF software control remains archived. The A2.32 runner must not import or use A2.31 heldout outcomes to determine action thresholds.

**Arm configurations per stratum:**
- **CUE:** both worlds contain B one cell east; one adds a perceptible creature on the eastern cell, the other does not; `local_threat_alerts=True` in both worlds, creating a genuinely first-person clue only in the cue arm.
- **INJURY:** both worlds contain B one cell east; one adds a *nonterminal*, hidden `danger_zone` on the eastern cell and the other does not. Body and initial physical settings are otherwise identical. No 'danger zone' label reaches Stage3. Report visible body-integrity change after a real physically applied movement and measure next-step actions. Never force I1 to replay a damaged life after death.
- **FAILURE:** both worlds contain local B at birth; one contains a logged external, one-attempt `collecter` failure schedule; the other does not. The first failed action still consumes physical time and body dynamics. Compare next-step inventory and actual later behavior. No access to the hidden forced-failure flag in prediction or cognitive memory.
- **INDISTINGUISHABLE:** both worlds contain B one cell east; one contains an otherwise invisible lethal zone on that cell, the other is safe. Compare exact preaction **authorized capture** (not whole hidden config) and model-origin actions. The death is a real mortality outcome, not a scientific falsification of sensory or predictive limits.

Within each pair execute two arm orders alternating by index parity. Do not interleave memory or physical worlds. Physical config remains the 32x32 normative WorldBody with 300-day/100-night steps and otherwise unmodified canonical values. Initial energy `65 + (i%3)`, food `13+i`, water `72+(i%4)`, integrity 100. Berry B quantity `4+(i%3)`. At most **four executed physical commands per life**; log early death/block/exception with denominators unchanged. No forced resurrection, no operator-created memories and no same-life rollback. Changes in day/night or body state are scored as physical context, not ignored.

## Outcome metrics, denominators and decision thresholds

**Four pre-registered primary outcomes, each with denominator eight paired worlds:**
1. CUE: fraction with a genuine `stage11_local_threat_alert_proposed` in the creature arm, none in the no-creature arm, and change (or absence) in the first action. **Software perception PASS:** 8/8 authentic cue asymmetries with journal provenance; less: FAIL. Behavioral discrimination is reported but is not required for perception PASS.
2. INJURY: fraction with an actually executed entry, reduced integrity observed in the next *authorized* capture, and a verifiable pre/post bodily difference. **Lived-feedback observation PASS:** at least six paired observed injuries and no after-death observations. Report Stage9/Stage11 admitted evidence, episode closure, memory references and subsequent action difference separately. Failure to change behavior may mean a missing learning route, or no safe action path, and does not itself prove ignorance.
3. FAILURE: fraction with an actually executed failed collection, new first-person inventory/resource evidence at the next capture, and whether the same collection is repeated. **Lived-feedback opportunity PASS:** >=6/8 physically failed acts with a follow-up capture and unchanged first-step inventory. **Learning claim:** requires >=6/8 changed subsequent action choices with corresponding *verified I1-lived evidence*, not just laboratory forced-failure truth. Otherwise mark **NOT DEMONSTRATED**, not a safety NO-GO.
4. INDISTINGUISHABLE: fraction of eight pairs whose preaction perception, model output and attempted choice match despite different hidden world labels. **Epistemic boundary PASS:** 8/8 identical preaction cues and zero secret labels in I1 model messages. Report deaths in both arms; deaths in the lethal arm are NOT used as an accuracy penalty where evidence cannot distinguish worlds. Differences in preaction decisions given identical inputs are a leak or determinism alert, requiring investigation.

**Hard NO-GO** if Oracle/hidden-world truth enters cognition, a postmortem event is called first-person, an actor acts after mortal death, an irreversible command is replayed, a Stage9/DC-05 veto is bypassed, an admitted action produces >1 effective transition, or model output claims safe/terminal/distal causal certainty without evidence. Report all deaths and noncompletions, even where they do not imply cognitive error.

**Outcome classifications:** `PERCEPTION_PASS`, `LIVED_OBSERVATION_PASS`, `LEARNING_DEMONSTRATED`, `LEARNING_NOT_DEMONSTRATED`, `INCONCLUSIVE`, and `EPISTEMIC_BOUNDARY_PASS` are independent axes. Science integration remains **NO-GO** until stronger blinded, independently reviewed autonomous cohorts, longitudinal memory evidence, genuine generalization and UC/survival audit. Never promote a Stage9 or Stage12 scientific status from a new test's success.

## Custody and analysis

Run one Python 3.11 and one Python 3.12 execution of the exact same 32 deterministic pairs, retain the same frozen corpus hash, pair IDs, operator-only outcomes, per-life independent WAL/journal hash, first-person event IDs and source-head SHA. **One cohort, two software repeats**. Run on actual mortal runtime, not pure model predictions. Train before constructing heldout births; never use any heldout life as training. The runner must produce complete JSONL per-life and a summary, with physical death/missingness separated from algorithmic prediction errors. Save operator-only labels outside I1 and hash chain evidence. Scientific decision is made against the pre-registered thresholds, never by post-hoc threshold changes.

**Important limitation:** this phase is an **audit of existing I1 learning**, not yet a proposal to insert a new memory owner or new food/toxic causal rule. If first-person adaptation is missing, describe the representational gap and propose a distinct I1-only hypothesis for A2.33 *after* examining this cohort. No unobserved danger should be smuggled into a newborn model.
