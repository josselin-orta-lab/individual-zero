## Causal question and competing hypothesis

Is the proven **0.35 -> 0.45** positive evidence for a previously *lived and recalled proximal collection* sufficient, in a NATURALLY generated multiple-action scenario, to alter real Competition crossing and the one command actually admitted by Action Control?

The comparison is I1 model-enabled **A2.35 ON versus OFF at birth**, with an externally trained but sealed model in both arms. This is not OFF versus no factorized model. The Stage11 geographic exploration option is the *existing* development-time opt-in, not an injected option or an operator choice. Both arms of a pair have identical external WorldBody, visible state, physics, and geographical settings; only the A2.35 recall option differs. A different compute-budget ceiling and extra review cost accompany the recall toggle by current architecture: report this as a possible confound, never treat a difference as proof of a pure memory causal effect.

**No adaptation claim** is allowed when the experimental model is the only non-wait admissible proposal. Evidence changes without genuine alternatives are counted separately, not promoted to decision learning.

## Freeze cohorts

- **Four strata x eight independent paired scenarios = 32 pairs, 64 different mortal I1 births.** Case IDs `i1:a235b:<STRATUM>:<INDEX>:<ARM>`, indices `00..07`, arms `on` and `off`; arm execution order alternates with index parity. One isolated WorldBody/Memory/Stage12 journal/WAL per birth; no experiences transferred between individuals. **12 maximum physical steps** per birth, stop at first death or invalid dispatch.
- `LOCAL`: local berry B, geography disabled (negative behavioral control).
- `GEO_LOCAL`: local berry B, Stage11 geographical exploration enabled for both arms; naturally observed frontier movement and local collection may compete.
- `GEO_FAILURE`: as GEO_LOCAL but the first `collecter` in BOTH arms is externally scheduled to fail once. The failure flag remains operator-only, never cognitively visible. Valid collection-success evidence may arise only from later physically verified successes.
- `HIDDEN_LETHAL`: no local berry, one east, unseen lethal cell immediately east in BOTH arms; geography disabled. At birth the hidden death is unknowable and not a predictive failure. Both arms receive the same hidden geometry. No postmortem learning, no survivor-only denominators.
- Starting body: energy `70+(index%3)`, food `12+index`, water `76+(index%4)`, integrity `100`. Berry B stock `16+(index%3)`; east cell is interior/passable absent lethal truth; no creatures, water sources, or obstacles; regular WorldBody 32x32 physical rules and default irrevocable mortal contract. No scripted movement, neural priming, operator-planted memory, alternate physics, or modified competition scores.
- **Training prior:** 16 newly physically executed independent lab transitions (8 `MOVE_E`, 8 `COLLECT_B`), before heldout births, fit with current source-approved factorized learner and freeze SHA-256/model version. It is not I1's lived experience. Training action types and parameters match the A2.34 lab corpus; case label and corpus digest differ.
- Same `Stage12DetectionPolicy` and Stage10 low-sleep fixture in both arms, both with `i1_model_enabled=True`; use the same Stage11 config within each pair. Forecast 2 UC, recall review 1 UC only when ON. Do not change other module parameters after seeing results.

## Full recording / primary endpoints

External observer may score technical journals/physical WorldBody only *after* the commands, never feed them into I1. Preserve `lives.jsonl` and independent WAL per life, model provenance, first-person captured body/inventory/adjacent, complete memory episodes, `memory_recall_proposed`, `s_t_published`, charged `i1_lived_recall_review` and `compute_charge`, option registration/evaluation, Competition traces and command admission. Require per-step `t_monde`, `cycle`, option ref and source ID lineage to distinguish temporally valid memory from next-step technical truth. Report exact per-life journal SHA and operator-only physical truth separately.

Each stratum denominator = 8 pairs, even if dead/no opportunity.
1. **Integrity:** 64/64 independent journals validate, 0 postmortem cognition, 0 duplicate physics transition and 0 false safety/terminal/causal certificate. Any violation is HARD NO-GO.
2. **Memory link:** eligible ON lives have `i1_lived_recall_review` source IDs matching past authenticated auto-committed first-person `command_experienced` and `world_transition_experienced` in the *same previous closed episode*, and a `memory_recall_proposed` present in that cycle's `S_t`. 0 fabricated/future/cross-life sources, else HARD NO-GO.
3. **Instrumental evidence:** score 0.45 only with verified positive success, otherwise 0.35. OFF stays 0.35 with **zero A2.35 review charge**; report all ON accepted/refused UC charges, not only successful upgrades. Any boosted score without evidence is HARD NO-GO.
4. **Genuine contest:** a pair has a genuine comparison opportunity only if both arms have >=2 NON-WAIT candidate options representing **distinct primitive commands**, with actual numeric evidence, in a shared world-step and before physical admission, including an A2.35-eligible model-origin `collecter`. Subsets selected after outcomes must not be changed. **A minimum 6/8 GEO_LOCAL pairs** is necessary to treat the stratum as a test of competing decisions; otherwise call result **INCONCLUSIVE / unavailable competition**, even if all ON reviews are correct.
5. **Choice difference:** in *eligible, naturally contested* pairs, count differences in applied physical primitive and verify respective Competition trace, crossing and Action Control authorization. **>=6/8 GEO_LOCAL pairs with genuine contest and different physically admitted primitive** is the preregistered narrow behavioral efficacy target. Report 0/8 or other negative values faithfully; at most this can justify more research, never deployment.
6. **Mortality and efficacy:** deaths, collection increments, body integrity/food, energy, UC cost and action veto in all 64 lives, including missing followup. Hidden-lethal deaths in indistinguishable worlds are not considered sensory failure. No scientific GO merely from increasing activity or changing command.
7. **M11**: software fingerprint on/off/1-vs-2UC distinction is previously PASS; an actual cold restart with a closed memory episode is an **independent unfinished requirement**. Do not call the birth contract test a cold-restart PASS.

**Statistics:** use simple paired counts with actual denominators, no post-hoc filtered hypothesis testing. Python 3.11 and 3.12 run the exact same 64 deterministic scenarios; this checks software reproducibility, not independent scientific replication. Retain all negative trials. Scientific status of I1 remains NO-GO pending stronger replication and cold recovery.

**Failure handling:** first infrastructure failure before any life may be fixed and documented without revising thresholds or world parameters. In-life cognitive exception counts in denominator; do not hide or replay it.
