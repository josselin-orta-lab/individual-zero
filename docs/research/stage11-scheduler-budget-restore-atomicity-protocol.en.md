## Concrete preexisting gap at branch HEAD 2b6199c707a1dab748cec323673e3732b8ea8551

The Scheduler's `CycleComputeBudget.charge` enforces per-module envelopes, `B_cycle` and the reserved safety/control capacity; `export_causal_state` records the current cycle, the whole-cycle total and per-module consumption. However, `restore_causal_state` currently accepts some inconsistent snapshots that **could never result from legitimate charges**, including a module total above its configured envelope, an ordinary-module sum exceeding `B_cycle - protected_capacity` while the global total remains in bounds, `True` used as an integer UC/cycle counter, and non-empty/consumed state without an open cycle. A forged extra field can also be silently ignored. Such a restore can invalidate subsequent `quote_operations` and `charge` decisions, and integrity of replay, even though restoration did not itself fail.

## Frozen, minimal implementation contract

1. Validate the **complete exported owner schema** `{config_version,cycle,consumed_cycle_uc,consumed_by_module}` without mutating active counters. Preserve exact successful round trips of every genuinely owner-produced state and their `canonical_causal_bytes`.
2. `config_version` must match current config. `cycle` must be exactly `int >= 1` or `None`. The latter is the unopened state and **requires both zero total and an empty map**. Reject bool/text/fractional cycles and negative/zero cycles.
3. The cycle total and each per-module number must be **exact** nonnegative `int` values (never bool). The map must contain only known module IDs of exact string type. Allow zero-UC map entries generated by charged zero-cost operations, and zero total for an opened cycle. No new configuration value, cost, fallback or schema key is introduced.
4. For each module, restored consumption must not exceed its P-43 envelope; `sum(module_consumptions) == consumed_cycle_uc`; the cycle total must not exceed `B_cycle`. Crucially, the sum consumed by **nonprotected** modules must not exceed `B_cycle - protected_capacity`. Legal control/protected-module spending still may use the reserved capacity; do not restrict it further. Validation must be independent of mapping iteration order.
5. On any invalid state, `restore_causal_state` raises `ValueError`, leaves the live Scheduler's exported state and canonical bytes unchanged, changes no journal/other owner, and does not create or consume a UC occurrence. A subsequent valid restore must still succeed. Commit staged validated data only after every check.
6. No changes to `charge`, `quote_operations`, `open_cycle`, operation-cost configuration, action/Planning choices, stage-11 hazard fixtures, historic hashes, SnapshotManager, scientific protocols or the normative specification. Existing published SHA-pinned results remain untouched.
