# Component ownership: compatibility entrypoint

This page is retained so historic agent handoffs and links do not break. It no longer maintains a second ownership table.

**Use the [Architecture Atlas](../architecture/ATLAS.md) as the single current cross-generation navigation map.** It identifies I0 (frozen), I1 (active) and I2 (unregistered proposal), shows actual intervention boundaries and links to generation-owned contracts and source files.

For task-specific files, use the [agent context router](AGENT_CONTEXT.md) and [machine-readable route map](../../config/agent-context-map.json). For research priorities, use the [global research coordinator](RESEARCH_COORDINATOR.md).

Before editing, verify the active generation in [the live engine registry](../../config/engine-registry.json), its `engine.json`, real callers, UC and M11 state ownership, actual Action Control admission and focused tests. A module's location alone does not establish active wiring or scientific evidence.

This page is **not** a specification, a scientific gate, or a substitute for the owning generation's documented runtime.
